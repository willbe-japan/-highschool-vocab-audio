# highschool-vocab-audio

大阪府公立高校入試 英語頻出単語帳（A/B/C問題 TOP100、重複除去）の発音音声ファイル置き場。

- 音声は `audio/{単語のslug}.mp3`（例: `audio/achieve.mp3`）
- edge-tts（Microsoft Edge TTS, en-US-AriaNeural, rate -15%）で生成
- GitHub Pages経由で配信し、単語帳PDFのQRコードから再生する

配信URL: `https://willbe-japan.github.io/-highschool-vocab-audio/audio/{ファイル名}.mp3`
